# Event sequences behind the S1-S4 verdicts

Generated by `spikes/causal/check.py` with the production recorder.
Format: `seq kind resource  tid=… eid=…`; `@N` = creation line in the fixture, `#N` = asyncId. Node-internal
resources (sockets, ticks, pipes) are omitted for readability; the full NDJSON is in `spikes/out/causal/`.
